# 第 10 课独立练习（不附答案，先自己完成）

**题 1：基础（10 分钟）**
输入 `"wosno21... "`，分别用 `for + Character` 与 `replaceAll` 统计数字、ASCII 字母、空白、标点数量。解释为什么 `replace("[^0-9]", "")` 不能工作。

**题 2：进阶（15 分钟）**
输入 `"ab12CD34!"`，使用 `StringBuilder` 分别抽取数字和字母，反转数字并输出：字母 `abCD`、数字 `1234`、倒序数字 `4321`。不得用 `replaceAll` 直接代替循环。

**题 3：边界（15 分钟）**
处理 `"a,b,,"`：分别使用 `split(",")` 和 `split(",", -1)`，分析数组的长度和内容。解释单纯 `split` 为什么不是完整的 CSV 解析器。

**题 4：挑战（20 分钟）**
使用 `"中A٣😀 "` 统计 Unicode 字母、数字、空白、其他字符数量（提示：阿拉伯数字 `٣` 是数字）。要求分类总数等于 `codePointCount`，并对比 `str.length()`。

**题 5：程序设计（20–30 分钟）**
实现 `analyze(String input)`，返回一个统计结果对象，调用端打印结果。对空串、含 Emoji、null（明确处理策略）测试；不得在分析方法中读取控制台。

**验收标准**：题 1～3 完成即可进入下一知识点；题 4～5 表明已具备处理真实文本和 API 设计的初步能力。
