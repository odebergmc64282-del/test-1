# 第 10 课增强版：Java 字符串处理体系

**学习目标**：区分不可变字符串与可变字符序列、解释 `replace` 与 `replaceAll`、独立完成文本分类与提取、理解 UTF-16 与 Unicode 码点的关系。

## 1. 知识地图

- `String`：不可变字符序列，`length()`、`substring()`、`split()`、`replace()`、`replaceAll()`、`equals()`。
- `StringBuilder`：可变字符序列，`append()`、`insert()`、`delete()`、`replace(int,int,String)`、`reverse()`、`toString()`。
- `StringBuffer`：提供同步方法的可变字符序列；普通单线程优先 `StringBuilder`。
- `Character`：字符/Unicode 码点判断，例如 `isDigit`、`isLetter`、`isWhitespace`。
- `Pattern`、`Matcher`：编译和执行正则表达式，适合复杂检索与提取。

## 2. String 不可变，不等于变量不能重新赋值

```java
String a = "Hi";
String b = a;
a = a + "!";
System.out.println(b); // Hi
```

这里 `a` 改为指向新字符串，`b` 仍指向原来的 `"Hi"`。对比：

```java
StringBuilder a = new StringBuilder("Hi");
StringBuilder b = a;
a.append("!");
System.out.println(b); // Hi!
```

`a`、`b` 引用的是同一可变对象。**提示**：不要使用 `==` 比较两个字符串的内容，用 `equals()`。

## 3. `replace()` 和 `replaceAll()` 的真实区别

```java
String s = "wosno21... ";
System.out.println(s.replace("[^0-9]", "").length());    // 11：按字面量替换
System.out.println(s.replaceAll("[^0-9]", "").length()); // 2：用正则删除非数字
```

- `[^0-9]` 表示匹配 **不是 ASCII 0–9** 的字符。
- `""` 是空字符串，删除匹配内容。
- `" "` 是包含一个空格的字符串，并不删除内容。
- `[^a-zA-Z]` 删除非 ASCII 英文字母；不能用于统计全部 Unicode 字母。

**验证法**：先打印 `replaceAll` 后得到的字符串，再调用 `length()`，避免只看数字而误判。

## 4. `split()` 使用正则表达式

```java
"a,b,c".split(",");            // [a, b, c]
"a.b.c".split("\\.");         // [a, b, c]，要转义正则特殊字符 .
" a   b ".trim().split("\\s+"); // [a, b]
"a,b,".split(",");            // [a, b]；默认去掉尾部空段
"a,b,".split(",", -1);        // [a, b, ""]；保留尾部空段
```

**注意**：`split(",")` 不能正确解析带引号的复杂 CSV，例如 `"苹果,红",2`。这时应使用可靠的 CSV 解析器或经过设计的持久化格式，而不是继续堆叠正则。

## 5. Java `char`、UTF-16 与 Unicode

`String.length()` 返回 **UTF-16 代码单元数量**，不是一定等于用户看到的字符个数。

```java
String s = "A😀中";
System.out.println(s.length());                  // 4
System.out.println(s.codePointCount(0, s.length())); // 3
```

原因是部分 Unicode 码点（如 😀）由两个 UTF-16 代码单元表示。因此文本分类若需支持各种语言和 Emoji，应考虑 `codePoints()` 或 `codePointAt()`。

还有：`Character.isDigit()` 识别多种语言的十进制数字；正则 `[0-9]` 只匹配 ASCII 数字，所以两种统计方法在某些输入下不同。

**进一步思考**：码点也不等于视觉字素簇，组合音标、部分 Emoji 序列可能由多个码点构成。

## 6. StringBuilder 和 StringBuffer

```java
StringBuilder sb = new StringBuilder("Java");
sb.append(" 17").insert(0, "Learn ");
System.out.println(sb);           // Learn Java 17
System.out.println(sb.reverse()); // 71 avaJ nraeL
```

`StringBuilder` 方法不会对整个字符串重新创建一个不可变 `String`，适合循环中连续构造文本。 `StringBuffer` 的主要方法具有同步机制，但**不能保证任意多步业务操作整体原子性**。

## 7. 代码练习的三层进阶

1. 基础：使用 `for + charAt` 统计数字、字母、空白和符号。
2. 进阶：使用 `StringBuilder` 提取数字、反转并格式化输出；与正则表达式结果对比。
3. 挑战：使用 `codePoints()` 处理汉字、全角数字、Emoji，验证分类总数与码点总数一致。

## 8. 常见错误汇总

| 错误 | 现象 | 处理 |
|---|---|---|
| 用 `replace` 传正则 | 匹配不到，长度不变 | 改 `replaceAll` |
| 用 `" "` 代替 `""` | 长度不减 | 删除时使用 `""` |
| `[a-zA-Z]` 当所有字母 | 汉字未统计 | 视需求用 `Character.isLetter` / Unicode 属性 |
| 用 `==` 对比字符串 | 相同内容可能判不同 | 使用 `equals` |
| 对 `split` 忘了正则转义 | `.` 等误匹配 | 正确转义或者 `Pattern.quote` |
| `split` 默认丢尾部空段 | CSV 末列为空时列数不对 | `split(",", -1)`（仍不适用复杂 CSV） |
| 将 `String.length()` 当字符数 | Emoji 结果异常 | 用 `codePointCount`，复杂显示用字素簇 API |
