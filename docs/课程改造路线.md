# 教学项目改造路线与抽查发现

## 目标人群

优先服务“学过 Java、但写代码需要频繁翻资料”的学生。每课采用：诊断题 → 关键原理 → 可运行范例 → 独立练习 → 自动化校验 → 复盘总结。

## 18 课的建议依赖顺序

- **复苏阶段（3–5 天）**：00–04（语法熟练度诊断），可根据测试直接跳过已掌握内容。
- **数据处理阶段（5–7 天）**：05 数组 → 06 方法 → 10 字符串（提前于原编号） → 新增 Unicode/正则表达式补丁。
- **面向对象阶段（7–10 天）**：07 类与对象 → 08 继承和多态 → 12 接口（先接口后深入泛型）。
- **标准库阶段（7–10 天）**：09 异常 → 11 集合 → 12 泛型 → 13 文件。
- **进阶阶段（7–14 天）**：14 Lambda/Stream → 15 并发，补 JVM 基础与内存模型。
- **实战阶段（10–20 天）**：16 控制台练习 → 17 图书管理系统，完成持久化、测试和重构。

以上不是全部必学天数；阶段通过独立编程考核才进入下一阶段。

## 代码抽查发现（需再全面校验）

1. `13_文件操作.java` 使用 `Files.writeString`、`Files.readString`、`Path.of`，需要 JDK 11+，与 README 所述最低 JDK 8 不兼容。
2. `17_项目实战.java` 使用 `"=".repeat(60)`，需要 JDK 11+。
3. `17_项目实战.java` 采用 `书名,作者,ISBN,借阅状态` 的简单文本格式和 `split(",")` 读取；字段中出现逗号就会错位，缺乏适当转义和严格校验。
4. `10_字符串操作.java` 的分割例子只覆盖了最简单的英文逗号，不足以解释正则表达式、尾部空值、连续空白、Unicode。
5. 教学源码集中在根目录内的独立 `.java` 文件，不便练习包结构、项目拆分、自动测试、持续集成。
6. 仓库根目录 API 列表未发现 LICENSE 文件；合并公开发布应先确认版权许可。

## 分期改造

| 阶段 | 优先级 | 交付物 | 验收方式 |
|---|---|---|---|
| V1 | P0 | 字符串章节补丁、知识路线、命令行自测 | JDK 17 编译、无第三方依赖的断言测试全过 |
| V2 | P0 | 为其余 17 课补充诊断题、分级练习、纠错清单 | 每课至少 2 个边界测试与 1 个独立题 |
| V3 | P1 | Maven 目录、JUnit 5、分层图书管理项目、数据存储 | `mvn test` + 基础功能测试通过 |
| V4 | P2 | MySQL/JDBC、Spring Boot、REST API、README 导航 | 对外提供可运行接口与 API 文档 |

## 推荐补足的概念（注意区别优先级）

- **P0**：String 与引用、equals、正则 `replaceAll`、`split` 限制、参数传递、集合 equals/hashCode、输入校验。
- **P1**：字符编码 UTF-8、Unicode 码点、不可变对象与可变对象、Optional、日期时间 API、资源释放、依赖管理和自动测试。
- **P2**：并发内存模型、CompletableFuture、JVM GC 基础、调优、数据库事务、Spring Boot、Web 安全基础。

## 课程设计规范

- 每个示例写明 **输入、预期输出、易错点、适用 JDK 版本**。
- 参考答案与练习分开放，避免学生不经思考复制。
- 性能结论使用“通常更适合”，不宣传所有场景下绝对更快。
- 代码演示若简化了业务边界（例如 CSV），必须明确声明并提示生产级替代方案。
- 每课提供“变式题”，检验能否独立迁移，而非只会敲原代码。
